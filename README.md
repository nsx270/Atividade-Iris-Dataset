# Classificação do Dataset Iris com SVM

Um projeto simples e direto de Machine Learning focado na classificação das espécies de flores do clássico dataset Iris, utilizando o algoritmo Support Vector Machine (SVM).

## Objetivo
O principal objetivo deste projeto é demonstrar o fluxo de aprendizado de máquina em um ambiente de notebook, contemplando:
- Obtenção e leitura dos dados.
- Análise Exploratória de Dados (EDA) e visualizações.
- Separação de dados em conjuntos de treino e teste.
- Criação, treinamento e avaliação de um classificador SVM (Kernel Linear).

## Tecnologias Utilizadas
- **Python 3**
- **Pandas** e **NumPy** (Manipulação e estruturação de dados)
- **Scikit-Learn** (Modelagem, treinamento e métricas)
- **Matplotlib** e **Seaborn** (Visualizações e gráficos)

## Principais Entregas
- **Acurácia do Modelo:** Avaliação de performance no conjunto de teste.
- **Matriz de Confusão:** Visão gráfica dos acertos e predições erradas por classe.
- **Importância das Features:** Gráfico de barras indicando quais medidas (sépala/pétala) tiveram maior peso na decisão do algoritmo.

## Como Executar
1. Clone este repositório em sua máquina local.
2. Certifique-se de ter as dependências instaladas (`pip install pandas numpy scikit-learn matplotlib seaborn`).
3. Execute o notebook localmente ou importe o arquivo no [Kaggle](https://www.kaggle.com/) anexando o dataset Iris.
